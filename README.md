## Project Title: Academic Grade Dispute Workflow System## 📌 Overview
A web-based automated workflow layer designed for Jomo Kenyatta University of Agriculture and Technology (JKUAT) to streamline the resolution of academic grade disputes (lost marks, score variations, etc.).
## ⚠️ The Problem
Current processes at JKUAT are manual, fragmented, and rely on physical follow-ups. This leads to:

* Lack of transparency and accountability.
* Coordination delays between students and administrators.
* Increased uncertainty and academic stress. [1] 

## 💡 The Solution
Instead of replacing existing academic databases, this project introduces a procedural workflow layer that:

* Provides a structured framework for students to lodge and track disputes.
* Automates task assignment and outlines administrative responsibility.
* Maintains an audit trail of all actions performed. [2, 3] 

## 🛠 Tech & Methodology

* Model: Iterative System Development.
* Architecture: Web-based Prototype.
* Phase 1: Analysis of current IT department dispute-handling workflows.
* Phase 2: Development of a functional web prototype.
* Phase 3: User Acceptance Testing (UAT) for functionality and usability.

## 🚀 Expected Impact

* Transparency: Real-time tracking of dispute status.
* Efficiency: Faster resolution times through automated routing.
* Integration: Enhances administrative processes without requiring a total overhaul of existing institutional systems.
